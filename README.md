# bmw-service.by — редизайн лендинга

Одностраничный сайт сервиса BMW в Минске. Тексты, формулировки и SEO-разметка
перенесены со старого сайта, оформление и структура — новые.

## Что залить на хостинг

```
index.html
assets/css/style.css
assets/js/main.js
images/…              ← те же пути и имена файлов, что и раньше
action.php            ← из server/action.php, в корень сайта
config.php            ← из server/config.sample.php, рядом с action.php
```

`index-old-backup.html` и папка `server/` на боевой сервер не нужны —
из `server/` берутся только два файла обработчика.

## Что сохранено один в один

| Элемент | Значение |
|---|---|
| `<title>` | Сервис BMW. Ремонт автомобилей БМВ в Минске |
| `meta description` | Только качественный ремонт для легендарных автомобилей BMW |
| `yandex-verification` | 7aaa75fd9d4dbe70 |
| Яндекс.Метрика | счётчик 37073655, вебвизор, цель `ZAKAZ` на отправке формы |
| Якоря разделов | `#home` `#service` `#onas` `#about` `#portfolio` `#handssection` `#contact` |
| Пути картинок | `images/…` — прежние URL, чтобы не потерять картиночную выдачу |
| Форма | POST на `action.php`, поля `user_name`, `user_email`, `text_comment` |
| Цель `ZAKAZ` | срабатывает только после успешной отправки, а не по клику |
| Ссылка на партнёра | otmotka.by (в подвале) |

Все тексты услуг перенесены дословно. Изменены только очевидные опечатки и
расстановка пробелов после запятых — ключевые слова и формулировки не тронуты.

## Что добавлено для поиска

- `lang="ru"` вместо `lang="en"` (на старом сайте была ошибка);
- `<link rel="canonical">` на `https://bmw-service.by/`;
- Open Graph и Twitter Card — превью при отправке ссылки в мессенджеры;
- микроразметка Schema.org `AutoRepair`: адрес, телефон, e-mail, цены на
  4 базовые услуги. Даёт расширенный сниппет в поиске;
- `alt` у всех изображений с ключевыми словами;
- один `<h1>` вместо семи, остальные заголовки — `<h2>`/`<h3>` с прежним текстом.

## Структура страницы

1. Первый экран + рейка двигателей (N63 N62 N52 N57 N47 N55 M57)
2. Бегущая строка со слоганами со старых слайдов
3. «Узнали свой BMW?» — симптомы
4. Услуги СТО — 6 блоков
5. Акция + полное ТО АКПП
6. **Болячки BMW** — один блок на все «болячки», внутри пять тем:
   N63/N62 → X-DRIVE → задний редуктор → замена цепей N57/N47 → чистка впуска
7. Отдельные работы — 11 блоков
8. Стоимость базовых услуг
9. Соцсети + галерея работ
10. Контакты, форма, карта

Раньше пять «болячек» были размазаны по странице отдельными секциями и читались
как статьи. Теперь это один раздел с липким индексом по моторам слева (на телефоне —
лента чипов сверху), подсветка активной темы идёт за прокруткой.

Каждая болячка разложена по одинаковым полкам: **симптомы → что делаем → что
получаете**, у X-DRIVE добавлено «если тянуть». Симптомы вынесены в список
загоревшихся ламп — владелец узнаёт свою машину до того, как начнёт читать.
Слова остались авторские, изменилась только раскладка. Тексты не спрятаны в табы —
всё остаётся в разметке и видно поиску.

В меню три пункта (ДВС N63, Замена цепей N57\N47, BMW F-series) свёрнуты в один —
«Болячки BMW», освободившееся место занял пункт «Цены». Ключевые слова из старых
пунктов сохранены в подвале: ссылки там ведут на те же якоря `#about`,
`#portfolio`, `#handssection`.

## Оформление

- Шрифты: **Geologica** (заголовки), **Onest** (текст и подписи),
  **JetBrains Mono** — только цифры и коды ДВС.
- Цвета: графит `#0A0B0D`, янтарь приборной лампы `#F5A623`,
  триада M (`#0C69B0` / `#14406E` / `#E4002B`).
- Иконки услуг — символы с приборной панели (check engine, тормоза, ABS,
  температура, руль, масло), нарисованы в SVG, ничего не грузится извне.

## Проверено

- Десктоп 1500 px, планшет 614 px, телефон 390 px.
- Клавиатурная навигация, `prefers-reduced-motion`, печать.
- Консоль браузера — без ошибок.

## GitHub Pages

В репозитории лежит `.nojekyll`, чтобы Pages отдавал файлы как есть.
Settings → Pages → Deploy from a branch → `main` / `root`.

Сайт откроется по адресу `https://kostapchuk.github.io/bmw-service-by/`.
Все пути относительные, так что подпапка не мешает. Два отличия от боевого сайта:

- форма вернёт ошибку — PHP на Pages не выполняется. Чтобы заявки работали и
  здесь, разверните `server/worker.js` (Cloudflare Worker) и пропишите его адрес
  в `FORM_ENDPOINT` в начале `assets/js/main.js`;
- `canonical` указывает на `https://bmw-service.by/`, поэтому превью на Pages
  не будет конкурировать с основным сайтом в выдаче.

## Локальный просмотр

```
cd bmw-service-redesign
python3 -m http.server 8777
# http://localhost:8777/
```

Форма локально вернёт ошибку — `python3 -m http.server` не выполняет PHP.
Проверить обработчик отдельно:

```
cp server/config.sample.php server/config.php   # вписать токен и chat_id
php -S 127.0.0.1:8899 -t server
curl -X POST -d 'user_name=BMW X5&user_email=+375291112233' http://127.0.0.1:8899/action.php
```

## Заявки в Telegram

Форма отправляет данные на свой обработчик, а он уже пересылает их боту.
Токен бота живёт только на сервере — в браузер и в этот репозиторий он не попадает.

1. `@BotFather` → `/newbot` → забрать токен.
2. Узнать `chat_id`: свой личный — у `@userinfobot`; для группы — добавить туда
   бота и взять id группы (он с минусом).
3. `cp server/config.sample.php config.php`, вписать оба значения, положить рядом
   с `action.php` в корне сайта. `config.php` в `.gitignore` — в git не уедет.

Что уже защищено: скрытое поле-ловушка для ботов, ограничение длины полей,
проверка что в номере хотя бы 7 цифр, очистка управляющих символов. Текст в
Telegram уходит без разметки, так что вставить в него ссылку или форматирование
через форму нельзя. Ошибки Telegram пишутся в лог сервера, посетителю наружу
отдаётся только общее сообщение.

**Не кладите токен в `assets/js/main.js`.** Всё, что в JS, видно любому
посетителю через «Просмотр кода» — с токеном чужой человек сможет писать от
имени вашего бота и читать переписку с ним.
